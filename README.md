## What the Project is About
Wildflower & Wax is an organic, home-based candle studio located in Pretoria, South Africa. This project focuses on moving the business from small physical marketplace stalls to a nationwide e-commerce site. For Part 2, the old static HTML layout files from the first phase are updated with a central external stylesheet and mobile media query rules so everything displays cleanly on smartphones, tablets, and desktops.


## What the Site Aims to Achieve
- **Main Goal:** Build an accessible, clean digital storefront to showcase collections and handle orders smoothly online.
- **Visitor Target:** Reach 1,500 monthly unique visitors within the first six months of launch.
- **Sales Conversion Target:** Achieve a minimum 3% shopper conversion rate.
- **Community Growth:** Gather 200 email newsletter sign-ups during the initial launch month.


## Step-by-Step Project Timeline
- **Phase 1: Concepts & Layout Planning (Days 1 to 3)**
  - Outlined the main objectives of the brand, calculated budgets, and defined target customers.

- **Phase 2: Semantic HTML Construction (Days 4 to 7)**

- **Phase 3: Central Style Sheet & Mobile Responsiveness (Days 8 to 11)**
  - Created a single style sheet file (`style.css`), set up universal font weights, and configured standard page colors.

- **Phase 4: Adding Code Explanations & Testing (Days 12 to 14)**
  - Wrote clear, helpful developer comments across all HTML code documents to address feedback gaps.
  - Tested layout boundaries using browser device inspectors to ensure text and grids align properly.


## Folder Map & Page Guide
- **`index.html` (Home Portal)** - The main greeting area featuring our custom background image banner and a brand feature overview.
- **`products.html` (Shop Catalog)** - A flexible e-commerce gallery displaying our 4 key candle lines side-by-side.
- **`about.html` (Our Story)** - Background information on the business and team details arranged in flex blocks.
- **`enquiry.html` (Inquiry Form)** - An interactive order sheet designed through external class selectors.
- **`contact.html` (Studio Locations)** - A split-screen layout mapping our physical Pretoria studios alongside an input mail sheet.
- **📁 css/style.css** - The central style sheet hosting global design elements, text tracking rules, and responsive media rules.
